# Connie Huang -- USP CUR E-Portfolio

This is my single-page e-portfolio built with plain HTML, CSS, and JavaScript. This can also be used as an easily modifiable template if you have zero idea how to code like I do, instructions below:

## What you would replace

Insert your own headshot, image/video of research, and resume/CV

1. **Headshot** -- `assets/img/whatever your headshot file is` is
   standing in for your photo. To swap it in:
   - Add your photo to `assets/img/`, e.g. `headshot.jpg` (remember to fix any sideways rotations)
   - In `index.html`, find `id="heroPhoto"` and change its `src` from
     `assets/img/headshot-placeholder.svg` to `assets/img/headshot.jpg`.
   - Remember to adjust the file type of photo in the code

2. **Résumé/CV PDF** -- `assets/resume/Connie_Huang_CV.pdf` can be replaced with whatever your CV is named. Export your CV as a PDF and drop it into the "resume" folder. Adjust the download buttons to download that filename. If you can't figure it out, you can also just rename your pdf Connie_Huang_CV.pdf and replace the current pdf. 

3. **Research Figure** -- Swap in a figure from your research under assets --> img, just replace the file "figure 3" and update the `src` in the Research section of `index.html`.
